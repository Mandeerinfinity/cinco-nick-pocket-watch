# CINCO™ Nick Pocket Watch

A fictional premium flagship pocket watch by CINCO Corporation, personalised for Nick. Time, Now With More Time.™

Nothing is for sale. No card is charged, nothing ships, no number is dialled, and nothing links out. The portrait stays on the device (localStorage). The only network call is optional weather from Open-Meteo, on request.

Live: https://mandeerinfinity.github.io/cinco-nick-pocket-watch/
